Installation
============

Stable release
--------------

To install Lorem Text, run this command in your terminal:

```
$ pip install lorem-text
```

This is the preferred method to install Lorem Text, as it will always install the most recent stable release.

If you don't have [pip](https://pip.pypa.io) installed, this [Python installation guide](http://docs.python-guide.org/en/latest/starting/installation/) can guide
you through the process.

From sources
------------

The sources for Lorem Text can be downloaded from the [Github repo](https://github.com/TheAbhijeet/lorem_text).

You can either clone the public repository:

```
$ git clone git://github.com/TheAbhijeet/lorem_text
```

Or download the [tarball](https://github.com/TheAbhijeet/lorem_text/tarball/master):

```
$ curl -OJL https://github.com/TheAbhijeet/lorem_text/tarball/master
```

Once you have a copy of the source, you can install it with:

```
$ python setup.py install
```
