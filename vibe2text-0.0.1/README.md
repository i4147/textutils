# vibe2text

**Транскрибация и расшифровка аудио и видео в текст с AI** — [Vibe2Text](https://vibe2text.ru).

Vibe2Text — онлайн-сервис распознавания речи на русском языке: переводит аудио и
видео в текст, разделяет говорящих (диаризация), расставляет таймкоды и добавляет
краткое содержание, список задач и чат по записи. Подходит для расшифровки встреч,
интервью, подкастов, лекций и телефонных звонков.

## Как пользоваться сейчас

**🌐 Веб-сервис.** Загрузите запись на [vibe2text.ru](https://vibe2text.ru) и
получите транскрибацию аудио в текст с разбивкой по спикерам, саммари и экспортом
в DOCX / PDF / SRT.

**🤖 Telegram-бот.** Пришлите голосовое, аудио или видео боту
[@vibe2text_bot](https://t.me/vibe2text_bot) — он вернёт расшифровку речи в текст
прямо в чате.

**🔌 MCP-сервер.** Для программного доступа и AI-агентов Vibe2Text поднимает
MCP-сервер на `https://api.vibe2text.ru/mcp`. Любой MCP-совместимый клиент (Claude,
Cursor, ваши пайплайны) может загружать записи, читать и редактировать транскрипты:

```json
{
  "mcpServers": {
    "vibe2text": {
      "url": "https://api.vibe2text.ru/mcp",
      "headers": { "Authorization": "Bearer mcp_xxx" }
    }
  }
}
```

Токен — в личном кабинете на vibe2text.ru. Подробнее: [github.com/vibe2text/vibe2text-mcp](https://github.com/vibe2text/vibe2text-mcp).

## Что умеет Vibe2Text

- 🎙️ **Транскрибация аудио и видео в текст** — распознавание русской речи онлайн
- 👥 **Диаризация спикеров** — кто что сказал
- 🕒 **Таймкоды и автоматические главы**
- 📝 **AI-саммари и action items** — краткое содержание и задачи из разговора
- 💬 **Чат по транскрипту** — вопросы к записи на естественном языке
- 📚 **Базы знаний и smart-отчёты** — семантический поиск по архиву расшифровок
- 🔗 **Импорт по ссылке** — транскрибация видео с YouTube, RuTube, VK, Vimeo
- 📄 **Экспорт** — DOCX, PDF, субтитры SRT
